## Licensing & Compliance Policy

1. **No Unlicensed / Ripped Assets**: Absolutely no assets extracted from Hollow Knight or any other copyrighted game may be committed to this project.
2. **Permissible Licenses**: CC0, MIT, Apache 2.0, BSD, or verified commercial licenses with clear distribution rights.
3. **Attribution Documentation**: If an asset requires attribution, the exact attribution string must be maintained in this file and rendered in the in-game credits screen before release.
